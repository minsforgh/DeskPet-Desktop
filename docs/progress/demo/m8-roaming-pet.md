# M8 데모: 화면 위를 돌아다니는 펫

> 데모 정의(milestones.md M8): 펫을 잡아 던지면 날아가 창 위에 사뿐히 착지한다. 걷다가 창 끝에서 내려가거나 옆 창으로 올라간다. 화면 왼쪽 끝으로 던지면 오른쪽에서 나온다.
>
> 근거: 아래 e2e 는 개발 제어로 가짜 창(지형)을 주입하고 시계를 당겨, 사용자가 보는 결과(펫 창 위치, 재생 상태, 서 있는 발판, 설정 창 화면 값, 디스크 파일)를 단언한다. 실제 PC 의 창 위에서 하는 확인은 사람 확인(H)이다. 종료 점검 실행 결과는 맨 아래 절에 있다.

## 없는 것

- 실제 창 위 화면 녹화·스크린샷: 개발 제어 `screenshot` 은 펫 창만 찍어 창과 펫의 관계를 보여 주지 못한다. 필요하면 사용자가 녹화해 `docs/progress/demo/` 에 둔다.
- 새 동작 그림: 내장 팩에 `climb`·`jump`·`fall`·`land` 등 새 상태 시트는 없다. 모두 기존 그림으로 대체 재생한다(ADR-0009 9-1). 그림은 아트 작업(완료 기준 아님).
- 배율이 다른 다중 모니터, 창이 많을 때 비용, 보안 프로그램 영향: 실사용(H)에서 확인.
