# M7 데모: 캐릭터 행동·아트

> 데모 정의(milestones.md M7): 내 팩에서 걷기 속도·잠들기 시간을 바꾸면 바로 반영된다. 새 시트로 `bow` 상태를 추가하고, 우클릭 "인사"로 순서 있는 동작(인사 → 안내 말풍선)을 실행한다. 4단계(D-048)로 Codex 플러그인, 알림 종류별 동작, 애니메이션 미리보기가 더해졌다.
>
> 근거: 아래 e2e 는 모두 사용자가 보는 결과(펫 상태, 말풍선 문구, 설정 창 화면 값, 디스크 파일)를 단언한다. 종료 점검 실행 결과는 맨 아래 "종료 점검 실행" 절에 있다. 사용자가 실제 앱에서 기준 6–9·11·13·14 를 확인했다(2026-10-09).

## 없는 것

- 설정 창 화면 스크린샷·녹화: 개발 제어 `screenshot` 은 펫 창만 찍고 설정 창 캡처 명령이 없다(M6 와 같음). 필요하면 사용자가 찍어 `docs/progress/demo/` 에 둔다.
- 실제 `bow` 아트: 내장 wolf-maid 에 `bow` 시트는 없다. e2e 는 임시 내장 팩과 테스트용 PNG 로 흐름을 확인했다. 실제 인사 그림은 아트 작업이다.
- 표정 유지: 알림·상호작용에 붙인 상태는 한 주기만 재생되고 idle 로 돌아간다. 말풍선이 떠 있는 동안 유지하는 것은 다음 마일스톤 첫 항목이다(사용자 결정, 백로그).
