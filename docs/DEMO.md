[![DeskPet 시연](progress/demo/deskpet-demo.png)](https://github.com/minsforgh/DeskPet-Desktop/releases/download/v0.1.0-preview.1/DeskPet-demo.mp4)

**[MP4 보기·다운로드](https://github.com/minsforgh/DeskPet-Desktop/releases/download/v0.1.0-preview.1/DeskPet-demo.mp4)** · 약 15초, 960×540, 무음·무자막.

| 구간 | 보이는 동작 |
|---|---|
| 0–2초 | 기본 wolf-maid 펫 |
| 2–7초 | 드래그 이동과 놓은 뒤의 반응 |
| 7–15초 | 공개 CLI로 보낸 수동 시연 알림 |

별도 사용자 데이터와 내장 팩 사본을 사용한 개발판의 실제 펫·말풍선 창을 캡처해 단색 배경에 합성했습니다. 드래그는 촬영용 제어 입력으로 재현했습니다. 바탕화면·다른 앱·계정 화면은 담지 않았고 원본 팩은 수정하지 않았습니다. 미리보기 이미지는 영상의 8초 지점입니다.

이 영상은 펫 이동과 수동 알림의 시연입니다. 실제 에이전트 작업 완료나 Orca 게이트 감지를 촬영한 자료와는 구분합니다. 다른 기능은 [README의 기능 소개](../README.md#무엇을-할-수-있나)에서 볼 수 있습니다.

## 발표 때 참고할 90초 설명안

아래는 앱과 공개 문서를 함께 설명할 때 쓸 수 있는 별도 순서입니다. 위의 무자막 영상에는 이 설명이 들어 있지 않습니다. 계정·개인 작업명·운영 DB가 보이는 화면은 사용하지 않습니다.

| 구간 | 보여 줄 화면 | 설명할 내용 |
|---|---|---|
| 0–15초 | 실행 중인 기본 펫, 드래그·상호작용 | “여러 AI 에이전트로 실제 앱을 개발하고, 실패를 다음 작업 규칙으로 연결한 사례입니다.” |
| 15–30초 | 아래 CLI로 보낸 말풍선 | “앱은 완료·질문·대기 상태를 알려 줍니다. 지금 알림은 계정 없이 보여 주는 수동 로컬 이벤트입니다.” |
| 30–50초 | [전후 비교 표](CASE-EVIDENCE.md)의 지연 사례 | “실제 Run 18개에서 가짜 테스트가 놓친 지연을 발견했습니다. 전체 읽기와 사용자 알림 시간을 나눠 확인했습니다.” |
| 50–70초 | [판단 표](CASE-EVIDENCE.md)의 D-076·D-078 | “AI가 만든 대사 구조의 의미와 실제 저장 결과를 검토했고, 분리 기준과 보존해야 할 데이터를 결정했습니다. 구현은 에이전트가 수행했습니다.” |
| 70–90초 | AGENTS의 렌더러 검증·실제 규모 규칙과 측정 한계 | “같은 실패를 줄이기 위해 다음 worker의 검증 조건을 바꿨습니다. 개발 전체의 생산성 개선은 아직 비교 측정 전입니다.” |

대본은 기록을 요약한 설명 예시입니다. 본인이 직접 설명할 수 있는 내용과 맞춰 사용합니다. 과거 지연 수치는 문서로 보여 주고, 새로 재현·촬영한 것처럼 설명하지 않습니다. 실제 Orca 게이트 시연을 녹화하려면 별도로 연동을 설정하고 그 결과임을 표시합니다.

## 소스에서 실행

Windows 10/11 x64, Node.js 22 이상, `package.json`의 pnpm 버전을 준비하고 루트에서 실행합니다.

```powershell
pnpm install --frozen-lockfile
pnpm exec electron --version
.\start-deskpet.cmd
```

스크립트는 호스트·CLI·앱을 빌드하고 wolf-maid 팩으로 시작합니다. `pnpm desktop:start`의 기본 팩은 placeholder이며 wolf-maid는 위 스크립트 또는 `--character=wolf-maid`로 선택합니다. 트레이에서 종료할 수 있습니다.

`electron --version`에서 바이너리가 없으면 설치된 패키지가 다운로드를 시도합니다. 첫 실행에 네트워크가 필요할 수 있으며 실패하면 오류를 먼저 확인하세요. 외부 연동 없이 표시·드래그·상호작용·설정을 시연할 수 있습니다.

## 2–3분 시연 순서

| 순서 | 보일 것 | 설명 |
|---|---|---|
| 1 | 기본 펫·드래그·상호작용 | 실험의 실제 산출물 |
| 2 | 트레이 설정 화면 | 캐릭터·플러그인·알림 설정 |
| 3 | 로컬 이벤트 말풍선 | 계정 없이 앱의 알림 결과 확인 |
| 4 | README·실패 사례·기준선 | 작업 방식과 검증 개선 설명 |

앱 실행 중 다른 PowerShell에서 루트의 CLI를 호출합니다.

```powershell
pnpm deskpet event --text "오케스트레이션 시연: 작업 결과를 확인해 주세요" --mood happy
```

이는 수동 로컬 이벤트이며 실제 worker 완료나 Orca 게이트 감지를 재현한 것으로 설명하면 안 됩니다. 실제 연동 시연은 자신의 Orca 환경·에이전트 hook을 설정한 뒤 진행합니다. LMS·Slack은 선택 기능이며 시연용 계정·토큰을 저장소에 넣지 않습니다.

## 설치 파일

```powershell
pnpm package
pnpm package:check
```

`release/`에 exe와 SHA256SUMS가 만들어집니다. `package:check`는 별도 점검용 앱을 임시 설치·실행·제거합니다. [이번 검증 상태](VALIDATION.md)와 [설치 안내](install.md)를 함께 참고하세요.

설치본에는 코드 서명이 없어 PC 보안 정책에 따라 막힐 수 있습니다. 평가자에게 보안 기능 해제를 요구하기보다는 녹화·스크린샷이나 개발 환경 시연을 제공합니다. exe와 SHA-256 파일은 [Preview Release](https://github.com/minsforgh/DeskPet-Desktop/releases/tag/v0.1.0-preview.1)에서 받을 수 있습니다.
