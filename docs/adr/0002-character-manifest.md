# ADR 0002: 캐릭터 팩 매니페스트 규약

## 상태

승인 (2026-10-06)

## 배경

`docs/plan.md` 6-3은 `characters/<id>/manifest.json` 예시로 캐릭터 상태와 대체 상태를 정의한다. 팩 제작과 코어 구현에 공통으로 쓸 타입, JSON Schema, 계약 테스트가 필요하다.

## 결정

매니페스트의 최상위 필드는 다음과 같다.

| 필드 | 형식 | 필수 | 제약과 의미 |
|---|---|---|---|
| `id` | `string` | 예 | 캐릭터 ID |
| `name` | `string` | 예 | 표시 이름 |
| `apiVersion` | 문자열 `"1"` | 예 | 현 매니페스트 버전 |
| `cellSize` | `[number, number]` | 예 | 각각 1 이상의 정수인 스프라이트 셀 크기 |
| `anchor` | `[number, number]` | 예 | 각각 0 이상, 대응하는 `cellSize` 값 미만인 정수; 발 위치의 공통 기준점 |
| `scale` | `number` | 예 | 0 초과 4 이하의 표시 배율 |
| `states` | `Record<string, CharacterState>` | 예 | 이름별 애니메이션 상태; `idle` 필수 |
| `fallbacks` | `Record<string, string>` | 예 | 요청 상태에서 대체 상태로의 매핑; 값은 `states`에 있어야 하고 키는 없어도 됨 |

각 `states` 항목의 필드는 다음과 같다.

| 필드 | 형식 | 필수 | 제약과 의미 |
|---|---|---|---|
| `sheet` | `string` | 예 | 팩 폴더 기준 상대 경로; `..` 경로 요소, 절대 경로, 역슬래시, URL 금지 |
| `frames` | `number` | 예 | 1 이상의 정수 |
| `fps` | `number` | 예 | 0 초과 60 이하의 재생 속도 |
| `loop` | `boolean` | 예 | 반복 여부 |
| `next` | `string` | 아니요 | 재생 종료 후 상태; `states`에 있어야 함 |
| `facing` | `"left"` 또는 `"right"` | 아니요 | 이 상태의 그림이 보는 방향. 없으면 방향 없는 그림으로 취급한다. 기존 팩과 호환되는 선택 필드다. |

스키마는 JSON Schema draft 2020-12의 TypeScript 상수로 내보낸다. 캐릭터 매니페스트 검증 함수는 스키마 규칙과 상태 간 참조, `anchor`의 `cellSize` 범위를 검사한다.
모르는 필드는 허용하며 검증기는 무시한다.
TypeScript 타입은 입력의 모양만 표현하고 길이·개수·정수·형식 제한은 스키마와 검증기가 책임진다.

## 버전 정책

기획안 5-5에 따라 기존 필드를 변경하거나 제거하면 API 버전을 올리고, 필드를 추가할 때는 유지한다. 코어는 현재 버전과 직전 버전을 함께 지원한다. 규약 변경은 `docs/adr/`에 기록한다. 현재 매니페스트 스키마는 버전 `"1"`만 받으며, 직전 버전 지원은 다음 버전이 생길 때 추가한다.

## 계약 테스트 위치

`packages/core/src/contracts.contract.test.ts`에 기획안 6-3의 `mochi` 매니페스트와 거부 사례를 둔다. `pnpm test:contract`로 따로 실행한다. 스키마 구조는 `packages/core/src/schemas.test.ts`에서 확인한다.

## 기획안과 다르게 정하거나 확정한 부분

- `apiVersion`은 정수 값을 담은 문자열 `"1"`로 확정했다.
- 6-3에는 매니페스트 타입의 필수 여부가 별도로 명시되지 않았다. 예시의 최상위 필드 전부와 상태의 `sheet`, `frames`, `fps`, `loop`를 필수로 정하고 `next`만 선택 사항으로 정했다.
- `frames: 0`을 거부해야 하므로 `frames`를 1 이상의 정수로 정했다.

## M2 에서 확정

- `cellSize`는 양의 정수 두 개, `anchor`는 0 이상이고 각 `cellSize` 값 미만인 정수 두 개로 정했다. `scale`은 0 초과 4 이하, `fps`는 0 초과 60 이하이다.
- `states.idle`은 필수다. `next`와 `fallbacks`의 값은 `states`에 있어야 한다. `fallbacks`의 키는 요청 상태 이름이므로 `states`에 없어도 된다.
- `sheet`는 팩 폴더 기준 상대 경로다. `/`로 나눈 요소는 비어 있지 않고 `.`나 `..`가 아니어야 한다. 요소에 제어문자(U+0000–U+001F, U+007F), 역슬래시, 콜론이 있거나 점 또는 공백으로 끝나면 거부한다. 앱과 검사기는 실제 경로를 확인하여 팩 폴더, manifest, 시트가 폴더 밖으로 이어지는 junction 또는 심볼릭 링크를 거부한다.

## D-029 선택 필드 voice

- 매니페스트에 선택 필드 `voice`(문자열)를 둔다. 값은 팩 폴더 안 어투 템플릿 파일의 상대 경로(예: `"voice.json"`)이며 `sheet` 와 같은 경로 규칙을 따른다(`..`·절대 경로·역슬래시·콜론 거부). 앱은 실제 경로를 확인하여 팩 폴더 밖으로 이어지는 링크를 거부한다. 필드 추가만이므로 `apiVersion` 은 `"1"` 을 유지한다.
- 파일 형식: `{"version":1,"templates":{"done":[…],"waiting":[…],"failed":[…],"info":[…]}}`. 각 kind 는 선택이고 변형 문자열 1~8개(넘으면 앞 8개만 사용), 변형 하나는 400 코드 포인트 이하다. 슬롯은 `{task}` `{result}` `{folder}` `{message}` 만 허용하며, 그 밖의 `{이름}` 이 든 변형은 버리고 로드 경고를 남긴다. 파일이 없거나 깨져도 빈 템플릿으로 동작한다(최대 64 KiB).
- 적용(D-032 의 `PetEvent.voice`): 해당 kind 의 변형을 kind 별 카운터로 순환 선택하고, 참조 슬롯이 비었거나 없는 변형은 건너뛴다. 쓸 변형이 없거나 템플릿이 없으면 보낸 `text` 를 그대로 쓴다. 결과는 공백을 정리하고 120 코드 포인트를 넘으면 119자 + `…` 로 자른다. 슬롯 값은 한 번만 치환하므로 값 안의 `{ }` 는 다시 치환되지 않는다.

## M6 선택 필드 추가

2026-10-09: 선택 필드 `meta`(author·version·license·description·createdWith), `preview`, `extends`(내장 팩만 원본, 깊이 1), `interactions` 를 추가했다. 필드 추가라 `apiVersion` 은 "1" 그대로다. 의미와 상한은 ADR-0007.

## M7 선택 필드 추가

2026-10-09: 선택 필드 `behavior`(행동 수치 기본값, 범위 밖이면 팩 거부·모르는 키는 무시), `sequences`(순서 있는 동작 파일 경로), `reactions`(알림 종류별 동작 파일 경로)를 추가했다. 필드 추가라 `apiVersion` 은 "1" 이다. 파생 팩은 `behavior` 를 키 단위로, `sequences`·`reactions` 는 파일 통째로 덮어쓴다. 상세는 ADR-0008 4·6·12장.

## 구현 한도

시트 파일 하나는 최대 8 MiB, 시트 이미지 하나는 최대 16,777,216 픽셀(폭 × 높이), 팩의 시트 파일 합계는 최대 64 MiB다. PNG 디코더는 IHDR로 계산한 압축 해제 크기를 zlib 출력 한도로 적용한다.
