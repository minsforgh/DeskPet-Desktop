# 공개 사본 안내

개인 개발 저장소의 현재 파일에서 만든 공개용 사본입니다. 원본 Git 이력과 에이전트 대화 원문은 포함하지 않습니다.

- 개인 사용자 경로는 Example 계정으로, 개인 Wiki와 다른 프로젝트명은 일반 이름으로 바꿨습니다.
- 운영 Run ID는 `run_public_번호` 별칭입니다. 실제 조회에 사용할 수 없습니다.
- 기존 문서의 커밋 해시는 비공개 기록 참고값입니다. 이 사본에는 해당 과거 커밋이 없습니다.
- 집계 수치·기간·실패 사례는 보존했습니다. 원본 로그와 저장소 밖 집계 도구를 포함하지 않아 독립 재계산에는 한계가 있습니다.
- 테스트 임시 폴더는 제외했습니다. 주간 집계 도구의 개인 기본 경로는 상대 경로로 바꿨습니다.
- 개인 개발 저장소와 별도의 공개 저장소로 배포합니다. 원본 개발 이력은 포함하지 않으며 설치본 릴리스는 별도로 제공합니다.

공개 커밋의 작성자는 GitHub 닉네임과 noreply 이메일을 사용합니다. ZIP을 다른 폴더에 풀어 Git 저장소를 새로 초기화한다면 작성자 설정도 다시 확인해야 합니다.
