## 설치 환경의 한계

이 PC의 pnpm 캐시와 기존 Electron 44.5.1 바이너리를 재사용했습니다. 의존성 설치만으로 Electron 바이너리가 준비되지는 않아 기존 설치의 dist와 실행 경로 표식을 사본으로 복사한 뒤 검증했습니다. **인터넷에서 내려받는 첫 설치나 새 PC의 완전한 초기 설치를 이번에 확인한 것은 아닙니다.**

초기 빌드는 샌드박스의 상위 디렉터리 접근 제한으로 실패했고, 허용된 샌드박스 밖 실행에서 통과했습니다. 실행 환경 제한과 앱 실패를 구분합니다. 이 사본 준비 중 제품 기능이나 테스트 단언은 바꾸지 않았습니다.

## 이번에 확인하지 않은 것

- 전체 단위 테스트·전체 e2e의 통합 회귀 검증. 관련 단위 테스트와 선택한 e2e만 실행했습니다.
- 실제 Slack·LMS 로그인·Orca 계정 환경의 모든 연동. 설치 점검에서는 민감 권한이 허용 대기인 상태도 정상으로 확인합니다.
- 새로운 Windows 계정·다른 PC, 재부팅 후 자동 시작. 과거 확인 이력은 [M9 데모](progress/demo/m9-installer.md)에 있으며 이번 결과와 다릅니다.
- M14 개선 후 오케스트레이션 지표. [STATUS](progress/STATUS.md)에 진행 중으로 남아 있습니다.

따라서 실행·설치 시연이 가능한 개발 중 실험 프로젝트로 소개합니다. 모든 PC에서 안정적인 완제품이라는 주장은 하지 않습니다.

## Jungle Bell 정리 범위

- 비공개 과거의 포팅 파일 `phase.ts`·`phase.test.ts`는 현재 트리와 공개 사본에 없습니다.
- 현재 `attendance-phase.ts`는 D-026에 따른 직접 작성 기록이 있고, 과거 파일과 비교했을 때 함수 인터페이스·분기·상수·날짜 포맷 구현이 바뀌어 있습니다. 동일한 출석 규칙과 KST·날짜 경계 처리는 공통입니다.
- 사용 방식 참고 사실과 과거 포팅·되돌림은 [출처 안내](PROVENANCE.md)에 명시하고 당시 라이선스·NOTICE를 보존했습니다. 이름을 지워 출처를 숨기는 정리는 하지 않았습니다.
