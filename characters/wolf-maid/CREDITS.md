# wolf-maid 아트 출처

DeskPet의 기본 캐릭터 팩입니다. 자세한 과정은 [아트 기록](../../docs/art/base/README.md)과 [결정 기록](../../docs/progress/decisions.md)에 있습니다.

- 콘셉트·앞모습·옆모습·인사 포즈 원본은 제작자가 AI 이미지 생성 도구로 제작했습니다.
- 앞모습 기준은 제작자가 직접 픽셀을 수정했습니다. 표정·걷기·인사 프레임은 코드 편집과 팔레트 정리로 만들었습니다.
- 제작자가 자신의 제작물로 공개하기로 결정했습니다. 기존 작품·캐릭터·작가 이름은 최초 콘셉트 프롬프트에 쓰지 않았습니다.
- 생성 도구와 사람의 수정 범위를 구분합니다. 코드·에셋의 별도 재사용 라이선스는 아직 지정하지 않았습니다.
