# 매일 점검

읽기 전용이다. 파일을 수정하지 않고, worker를 띄우지 않는다.

1. `docs/progress/STATUS.md`만 읽는다. 다른 진척 문서는 읽지 않는다.
2. "현재 마일스톤" 표의 완료 기준이 모두 ✅ 충족이거나 🙋 사람 확인 대기면, 맨 위에 한 줄로 알린다:
   "M<n>을 닫을 수 있습니다. 사람 확인 항목을 처리한 뒤 `/milestone-close <n>`을 실행하세요."
   ⏳ 진행이나 ⛔ 막힘이 하나라도 있으면 이 줄은 쓰지 않는다.
3. 사용자가 오늘 처리해야 할 것만 다음 순서로 알린다. 각 항목은 한 줄로 쓴다.
   1. 사람 확인 대기
   2. 결정 대기
   3. 경고 신호
4. 해당 항목이 없으면 "없음"이라고 쓴다.
5. STATUS.md의 "마지막 갱신"이 이틀 이상 지났으면 그 사실을 한 줄로 덧붙인다.

진행 상황 요약이나 다음 작업 제안은 덧붙이지 않는다.
